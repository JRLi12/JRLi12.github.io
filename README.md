## Deploy to GitHub
GitHub does **not** automatically unpack a ZIP uploaded to a repository. Unzip this package first, then place/push the **contents of this folder** into the root of the `JRLi12/JRLi12.github.io` repository.

If using GitHub's web interface, upload the extracted files/folders (not the ZIP itself). After the commit, GitHub Pages should publish at:

https://JRLi12.github.io/

## Updating the CV later
Replace `assets/files/Jierui_Li_CV.pdf` with the revised PDF while keeping the same filename. The homepage CV link will stay unchanged.
